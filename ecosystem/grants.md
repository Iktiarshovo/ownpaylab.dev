# OwnPay Developer Grants Program

The OwnPay Grants Program funds open-source builders, researchers, and developers expanding the capabilities of our dual-rail settlement infrastructure.

---

## 1. Focus Areas

- **Open Source SDKs:** Idiomatic client libraries for Go, Rust, Ruby, Elixir, and Swift.
- **E-Commerce Plugins:** Native plugins for Shopify, WooCommerce, Magento, PrestaShop, and Medusa.
- **Agentic Commerce Tools:** Frameworks integrating OwnPay MCP servers with AutoGPT, CrewAI, LangChain, and LangGraph.
- **Security & Formal Verification:** Independent audits, fuzz testing suites, and property testing tools for settlement protocols.

---

## 2. Grant Tiers

| Tier | Funding Range | Target Scope | Timeline |
| :--- | :--- | :--- | :--- |
| **Micro Grants** | $1,000 – $5,000 | Minor SDK enhancements, tutorials, bug fixes | 2–4 weeks |
| **Builder Grants** | $5,000 – $25,000 | Production CMS plugins, framework libraries | 1–3 months |
| **Strategic Grants** | $25,000 – $100,000 | Major protocol implementations, core infrastructure | 3–6 months |

---

## 3. How to Apply

Submit an issue on [GitHub](https://github.com/Iktiarshovo/ownpaylab.dev/issues) using the `[FEAT]` template or email [`grants@ownpaylab.tech`](mailto:grants@ownpaylab.tech) with your proposal, architecture specification, and milestone breakdown.
