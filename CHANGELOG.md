## [1.0.0] - 2026-09-15

### Added
- **Initial Public Release of OwnPay Developer Lab (`ownpaylab.dev`)**:
  - Comprehensive documentation for the OwnPay Dual-Rail Settlement Architecture (Human Commerce & Autonomous AI Agent Rails).
  - Protocol specifications for `PaymentIntent`, `x402` HTTP Payment standard, MCP (Model Context Protocol) integration, and webhook security.
  - SDK integration guides and quickstarts for TypeScript/Node.js, Python, and Next.js.
  - Full institutional transparency suite:
    - Master Statement & Long-Term Philosophy
    - Core Principles & Master Allocation Framework (`35%` Founder/Co-founder, `25%` Dev/Ops, `25%` VC/Investors, `15%` Ecosystem/Community)
    - Security Model, Threat Boundaries, and Responsible Disclosure Policy
    - 2026–2027 Engineering & Milestone Roadmap
  - Standardized open-source governance: `SECURITY.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SUPPORT.md`, `CITATION.cff`.
  - Canonical 4-domain routing reference (`ownpay.tech`, `ownpaylab.tech`, `ownpaylab.dev`, `ownpay.me`).
  - GitHub Actions automated CI workflows for Markdown validation and link integrity.
  - Production-ready runnable code examples for merchant checkout, agent autonomous payer, and express webhook signature listeners.
