## Stability Tiers

We classify roadmap items into four distinct status tiers:
- **`[STABLE]`**: Shipped, production-validated, covered by regression tests.
- **`[DEVELOPMENT]`**: Active codebase implementation, undergoing testnet verification.
- **`[PLANNED]`**: Formally architected, prioritized for upcoming development cycles.
- **`[FUTURE]`**: Conceptual research, subject to protocol RFC discussion.
