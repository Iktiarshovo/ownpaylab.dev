# Responsible Vulnerability Disclosure Program

OwnPay values the vital contributions of independent security researchers and the broader Web3 security community. We are dedicated to working collaboratively with researchers who discover potential vulnerabilities.

---

## 1. Contact Information

- **Dedicated Email:** [**`security@ownpaylab.tech`**](mailto:security@ownpaylab.tech)
- **Response Commitment:** Initial acknowledgment within **24–48 hours**.

---

## 2. Submission Guidelines

When reporting a vulnerability, please include:
1. Clear description of the vulnerability and its potential impact.
2. Step-by-step instructions or minimal PoC code to reproduce the issue.
3. Affected components, SDK versions, or smart contract addresses.
4. Any remediation suggestions if known.

---

## 3. Safe Harbor & Legal Protection

We will not pursue legal action against researchers who:
- Conduct security testing within the scope of our [Security Policy](../SECURITY.md).
- Avoid accessing or modifying customer or merchant production funds.
- Refrain from disruptive testing (DDoS, spamming, social engineering).
- Allow us reasonable time to remediate issues before making public statements.
