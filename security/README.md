# OwnPay Security & Threat Modeling Hub

Security and deterministic execution are the foundation of OwnPay's settlement architecture. This directory publishes our public security model, threat analysis, trust boundaries, and audit roadmaps.

---

## Security Documentation Map

```text
security/
├── README.md                   # Security hub overview
├── security-model.md           # Core security model & cryptographic primitives
├── threat-model.md             # Threat analysis, attack surfaces & mitigations
├── trust-boundaries.md         # Component boundaries, data isolation & zero-trust
├── responsible-disclosure.md   # Vulnerability handling & security contacts
└── audit-roadmap.md            # Smart contract audits, penetration testing & timeline
```

---

## Vulnerability Reports

To report a vulnerability, review [Responsible Disclosure](./responsible-disclosure.md) or email [`security@ownpaylab.tech`](mailto:security@ownpaylab.tech) directly. Do not open public GitHub issues for security matters.
