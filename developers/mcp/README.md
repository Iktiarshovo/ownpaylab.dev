# OwnPay MCP Developer Reference

The **Model Context Protocol (MCP)** server allows AI assistants and autonomous agents to interface with OwnPay safely.

---

## Directory Overview

- **[Tools](./tools.md):** Detailed tool schemas and JSON-RPC specifications (`ownpay_get_balance`, `ownpay_create_intent`, `ownpay_pay_invoice`).
- **[Resources](./resources.md):** Dynamic MCP resources and context prompts for agent instruction.

---

## Quick Server Run

```bash
npx -y @ownpay/mcp-server
```
